# Usage
## Interactive
1. Run dns.bat as Administrator.
2. Select an option.

### Option 1 – Custom DNS
- Primary DNS: Defaults to 1.1.1.1
- Secondary DNS: Defaults to 1.0.0.1
- Press Enter to accept either default.

### Option 2 – Restore
- Automatically restores DNS configuration to DHCP.
- No need to enter any DNS addresses.

##### Note: This version configures IPv4 DNS only. If multiple adapters have default gateways, it selects the first one detected.
